MEDICARE · COLLEGE PROJECT

Healthcare management, made simple.

MediCare is a full-stack hospital management system designed to bring patients and doctors into one clean, practical digital workflow.

What is MediCare?

MediCare demonstrates how a modern healthcare portal can handle authentication, profiles, appointments, prescriptions, billing and doctor availability from a single responsive interface.

How the system works

Patients can discover doctors and manage visits, while doctors get their own role-aware workspace for appointments, availability and patient-related workflows.

Core modules

Patient and doctor accounts · Dashboard · Doctor discovery · Appointments · Rescheduling · Prescriptions · Billing · Profiles · Availability · Theme support.

Technology stack

Python, Flask, SQLAlchemy, PostgreSQL/SQLite, HTML5, CSS3 and vanilla JavaScript, with a responsive frontend built for practical learning and demonstration.

Project purpose

This project focuses on applying full-stack development concepts: authentication, database-backed CRUD workflows, role-based interfaces, API communication and responsive UI design.
