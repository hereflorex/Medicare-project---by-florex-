ABOUT MEDICARE

A modern hospital management system for a smoother care journey.

Built with Flask, SQLAlchemy, PostgreSQL and a responsive vanilla JavaScript interface.

Our mission

MediCare connects patients and doctors with a single, understandable workflow: identity, appointments, prescriptions, profiles and billing.

Technology

Python + Flask backend, SQLAlchemy ORM, PostgreSQL database, semantic REST APIs, secure password hashing and session authentication.
